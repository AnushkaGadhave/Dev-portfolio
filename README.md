# 3d-mod-web

An interactive 3D portfolio web application built with React, Three.js, React Three Fiber, and GSAP.

## Features
- **3D Dog Model & Animations**: Built using `@react-three/fiber`, `@react-three/drei`, and custom WebGL Matcap shaders.
- **ScrollTrigger Animations**: Smooth GSAP camera and model rotation tied to page scroll.
- **Dynamic Matcap Shader Transitions**: Interactive project hover effects triggering real-time material switches on the 3D model.
- **Responsive & Modern Design**: Dark aesthetic with custom typography and layout.

## Tech Stack
- **Framework**: React 19 + Vite
- **3D & Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations**: GSAP, `@gsap/react`, ScrollTrigger
- **Icons**: Remix Icon

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
